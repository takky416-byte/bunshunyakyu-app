# 2026年推定年俸を用いるシミュレーションルール

ルールID：`2026-salary-proxy-v2`。ユーザーの合意に基づき、2026年推定年俸を翌季年俸の代理として使用する。2027年俸を用いる実開催時の厳密な資格判定とは異なる。出典と過年度からの変更は [RULE_RESEARCH.md](RULE_RESEARCH.md) に記載。

## 候補資格

- 2026年度公式名簿・成績はNPB。推定年俸はgurazeni.comの2026年度一覧で氏名または背番号・守備位置と生年月日を照合。1,067名中1,010名の金額を収録。
- 公式FA資格者105名、2025年現役ドラフト加入者12名をNPBの選手IDで照合し除外。育成登録、2026年俸1億円以上も除外。
- 日刊スポーツの退団一覧で一致する戦力外・退団・引退報道は、今回の仮想候補から除外する。これは開催時の契約保留名簿の確認に代わるものではない。
- 金額未確認は保留。外国出身者は国籍・外国人扱いを生年月日や名前から決めつけず、区分未照合として保留する。外国出身の日本人を外国人と断定していない。
- 複数年契約、過去のFA行使、開催時の契約保留名簿等は全選手を確認できていない。選択可能でも「仮対象」「契約等未確認」と表示する。NPCにも同じ候補除外を適用する。
- 2026年10月14日の改定を日刊スポーツと翌15日のスポニチ本文で再確認。7月31日までの通常トレード等による加入は、それだけを理由には除外しない。前年現役ドラフト加入者の除外とは独立する。開催年の年度連盟選手権試合終了翌日以降の譲渡獲得・育成から支配下への移行は除外対象。選手別の加入・昇格時期は最終照合が必要で、候補画面とルール説明にもこの違いを明記する。
- 原則2名以上。5,000万円以上1億円未満を1名含める場合は、5,000万円未満を確認できる選手2名以上と合わせ、計3名以上。例外を2名、1億円ちょうど、金額不明を通常枠と数える提出を禁止する。
- 利用者取り込みデータの `eligible` は利用者の確認フラグとして扱う。未収録の年俸を推測で0円にせず、年俸不明は例外枠の通常2名には数えない。

## 第1巡

各球団が他球団の候補を1名予備指名し、所属球団の得票数で暫定順位を決める。同票は2026年新人ドラフト第2巡順：楽天、中日、ロッテ、ヤクルト、オリックス、広島、日本ハム、DeNA、西武、巨人、ソフトバンク、阪神。根拠はNPB公式2026年選択選手一覧の球団順とサンスポの解説。

最初は暫定順位1位が予備指名した選手を獲得し、その元所属球団に指名権が移る。既に獲得済みの球団へ戻る場合は未獲得球団の暫定順位で再開する。予備指名先が指名可能な限り別選手へ変更できない。既に放出済み等で指名不能なら、指名可能な別候補を選ぶ。11番目の指名は12番目の球団から選ぶ。全球団が各1名獲得・1名放出して終了。

## 第2巡

1. 獲得希望で参加／放出のみで参加／不参加を選択する。
2. 12球団の意向を表示し、自球団の意向・入札条件・希望順位を再確認する。確定前は意向変更可能。NPCの意向はシードで決まり、この画面では固定。これは実球団の意向の再現ではない。
3. 参加確定後は不参加へ切り替えられない。獲得希望の球団は1名以上の希望を優先順付きで入札。
4. 入札は「無条件」（人数増減を許容）または「獲得と放出が均衡する場合のみ」の2条件。
5. 無条件を優先し、同条件は第1巡の実際の指名順の逆順を優先する。参加球団の残り候補から、獲得・放出が各最大1名になる成立可能な組合せを探索する。
6. 均衡条件は獲得と放出が両方成立、または両方不成立の場合だけ受理。3球団以上の交換も扱う。放出のみ、獲得のみ、不成立も結果として認める。

報道は入札条件と競合順位を示す一方、NPB議長による複数の成立可能な組合せの内部調整手順までは公開していない。この実装は優先順位上位の入札・希望順から、全条件を満たす組合せを採用する決定的な調整方式。単純な貪欲法で後続の均衡条件を壊さず、成立可能性を全体で検証する。実際の議長の判断結果との完全一致を保証するものではない。

## 保存と再現

旧版はルールが異なるため、保存キーをv2に分ける。旧v1記録は消去せず保持し、初回に案内する。v2では候補提出・予備指名・指名・第2巡意向・確定入札を合法な遷移で再実行して保存データを検証する。第2巡の未確定な希望選択は保存対象外。

## 発表演出

指名順、各球団の指名、第2巡の成立結果は、発表待ちから結果表示へ段階的に進む。NPCを自分の番まで進める場合も各指名を順に表示する。演出は結果・指名順・乱数を変更せず、発表した時点の合法な状態だけを保存する。待機中に再読み込みした場合は直前に保存した状態へ戻る。スキップ時は残りの合法な指名まで進み、二重指名しない。演出の有無は端末に保存し、ブラウザの「動きを減らす」設定では演出を省略する。
