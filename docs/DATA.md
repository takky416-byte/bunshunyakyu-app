# 選手データと確認範囲

## 公式スナップショット

- 取得日：2026-10-24（日本時間）。取得日以降の移籍・契約変更は反映しません。
- 出典：NPB公式の2026年度選手一覧12ページ、2026年度個人打撃成績12ページ、個人投手成績12ページ。
- 名簿URL形式：`https://npb.jp/bis/teams/rst_{team}.html`。**名簿には年度がパスに入らない**ため、取得時に見出しが2026年度であることを検証します。
- 成績URL形式：`https://npb.jp/bis/2026/stats/idb1_{team}.html` / `idp1_{team}.html`。
- 球団ID：t / g / db / c / s / d / h / f / m / e / b / l。
- 保存項目：選手ID、氏名、所属、守備位置、背番号、生年月日、投打、登録区分、注記、一軍成績、出典。
- 投球回の `11.2` は11回2/3を表す文字列として保持します。小数の11.2回に変換しません。
- 公式ページに一軍成績行がない選手は `stats: null`。欠測値を推測したり、成績をゼロとして捏造したりしません。
- 成績の名前照合では空白と投打記号を除き、球団別に対応付けます。各選手の公式IDは名簿リンクから取得します。
- 打撃OPSは公式出塁率＋長打率から計算した表示用の和です。
- 最終出力は全ページの取得・年度確認・構造確認・選手ID重複確認が通った場合だけ置換します。

元HTMLのハッシュは取得内容を識別するためのもので、第三者による署名や資格確認を意味しません。

## 現役ドラフト参加資格との違い

**支配下登録だけでは現役ドラフトに参加できるとは限りません。** 外国人・FA・年俸・複数年契約など、契約に関係する条件は現在のスナップショットにありません。確証のない年俸や契約内容を生成していません。

公式名簿内の `eligible` は、この暫定版の画面で選択可能かという内部フラグです。支配下選手をtrue、育成選手をfalseとしています。`eligibility: unverified` を付けており、参加資格の確認済みを意味しません。NPCもこの暫定選択範囲から候補を提出するため、実際には提出できない選手を選ぶ場合があります。

正確な2026年の体験にするには、ルールの細則と選手の対象条件を照合し、除外対象・条件付き対象・未確認を区別したデータの追加が必要です。非公開の実際の提出リストを知っていることにはしません。

## ゲーム用の設定

各球団の補強ポイント、候補選考、参加判断、適合度は独自のゲーム用設定です。球団の実際の意向や選手の市場価値を表しません。

ゲーム内適合度は一軍出場量・一軍成績・設定上の守備位置需要・シード固定の変動から計算します。一軍成績のない選手にはゲーム用の基準点を使います。これは架空の実績を補間する処理ではありません。年齢による予測、負傷情報、年俸は評価に使用していません。

## 利用者提供JSON

アプリ内「選手データ」から形式と空のひな形を確認できます。`version: 1`、`season: 2026`、2026年内の有効な `asOf`、データ名、各球団2名以上の選択可能な選手が必要です。ID・正規化後の選手名の重複、不正な守備位置・球団ID・URL・日付を拒否します。1ファイル1MB・1,500名までです。

取り込みは形式の検査であり、出典・所属・資格の照合ではありません。資格確認済みの候補だけ `eligible: true` にしてください。任意のファイル内の追加項目や成績は、未検証のまま公式成績として扱わないため取り込みません。

## 以前の参考データ

`src/data.ts` に残っている72名は、最初の操作確認とエンジン試験のための過去所属の手入力参考データです。現在の既定データではありません。以前の参考版で進行中の保存ゲームがある場合に限り、そのゲームを再開できるよう保持しています。2026年の所属や資格の根拠としては使用しません。

写真・球団の公式ロゴは取り込んでいません。画面の球団マークは独自の文字図案です。

## 2026年推定年俸による仮判定（ユーザー合意）

`src/eligibility2026.json` を名簿の公式IDへ結合。年俸はgurazeni.comの2026年球団別一覧を出典とする推定値で、公式発表額とは表示しない。氏名または背番号・守備位置と生年月日を照合し、一意に対応できた1,010名だけ収録する。未照合57名を0円などで補完しない。

公式FA資格者と前年現役ドラフト加入者はNPBページの選手IDで照合する。戦力外等の報道は日刊スポーツの一覧本文にある選手氏名と状態を照合し、今回の仮想候補から除外。育成再契約打診など報道時点の状態を開催時の確定名簿とはみなさない。外国の出身地だけでは外国人選手と断定せず、該当者は確認保留とする。多重契約・過去FA行使の非公表部分等は残るため、選択可でも仮対象と表示する。

更新スクリプトは当日の生HTMLをキャッシュし、出典URL・取得日・ハッシュ・金額・既知除外理由・保留理由・未確認事項を保存する。全ページが年度・構造確認に通った後だけファイルを置換する。公式名簿が更新されて条件データにない選手が加わった場合も、条件データ更新まで保留にする。
