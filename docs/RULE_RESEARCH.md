## 確認できた2026年の開催・対象条件

開催日は2026-12-09。A/Bで照合した。

候補は契約保留選手名簿に載る選手から選ぶ（E/F）。シーズンの登録名簿に名前があるだけでは、開催時点で候補にできるとは限らない。

Aが列挙する対象外の区分は以下。年俸については例外枠がある。

1. 外国人選手。
2. 複数年契約の選手。
3. 翌季年俸5,000万円以上の選手。ただし1名だけ5,000万円以上1億円未満を候補に含められる。
4. FA権を行使したことのある選手。
5. FA資格を持つ選手。
6. 育成選手。
7. 前年の現役ドラフトで獲得した選手。
8. 開催年の年度連盟選手権試合終了翌日以降に、契約譲渡で獲得した選手。
9. 同じ基準日以降に育成契約から支配下契約へ移行した選手。

2026年は通常のトレード等で獲得した選手の除外期間が短縮され、前年オフから2026年7月31日までの加入選手も、他の条件を満たせば対象にできる。前年現役ドラフト加入者の除外は独立した条件なので、通常トレードと混同しない。

E/Fによる候補人数は2名以上。高年俸例外を使う場合、5,000万円未満の選手を2名以上含め、合計3名以上にする。1億円ちょうどは例外に含まれず、5,000万円ちょうどは例外枠になる。

実開催の厳密な判定には翌季、すなわち2027年の年俸情報が必要。ただし、この調査後にユーザーと合意し、今回のシミュレーションでは2026年推定年俸を代理として明示的に使用する。未更改・非公表契約は「未確認」とする。Eや日刊の球団別記事も、推定年俸や非公表の複数年契約について留保している。

## 第1巡で確認できた仕組み

- 球団ごとに他球団の候補から獲得希望を予備指名する。候補を出した球団に集まった希望数で暫定順位を決める（E/F/G）。
- 同票は抽選ではなく、その年の新人ドラフト第2巡の指名順を使用する（F/G）。2026年の具体的な球団順は、当年の順位と新人ドラフトの公式選択順を別途照合して設定する。
- 本指名は原則として予備指名で通知した選手。希望選手を出した球団が既に放出済みなど、指名不能の場合は未放出球団から選び直す（G）。
- 指名された選手の元所属球団に指名権が移り、既に獲得済みの場合は未獲得球団の暫定順位で再開する（G）。
- 11番目の指名球団は12番目の指名球団から選ぶ（F/G）。
- 各球団が必ず1名獲得・1名放出する（E/F/G）。

第1巡の細則は主に過年度の詳細報道から確認したもの。2026年の改定が対象範囲に関するものだという事実を、全条文に他の変更がないという証明にはしない。

## 第2巡：2025年改定で確認できた手順

C/Dで確認した内容を自分の言葉で整理する。

- 最初の意向は、獲得を希望して参加／放出のみのため参加／不参加の3区分。
- 他球団の意向を共有し、参加希望球団が再確認する。確認は第1巡の実際の指名順の逆順。状況が変われば確認を繰り返す。
- 参加確定後、入札段階では不参加へ変更できない。
- 獲得を希望する球団は、希望する選手を優先順付きで入札する。
- 入札条件は、人数の増減を許容する「無条件」と、獲得・放出が均衡する場合だけ成立する条件の2種類。
- 無条件が優先。同じ条件で競合する場合は、第1巡の実際の指名順の逆順が優先。
- 条件が成立しなければ第2巡の移籍は成立しない。必ず参加球団が各1名ずつ交換する制度ではない。
- 本指名は第2巡まで。

現在のアプリの「仮想第2巡」は、この入札制度を実装していない。2026年版へ適用する際は、2026年の他の改定有無と譲渡の成立判定を引き続き照合する。

## 調査時点の差分（対応前の記録）

| 項目       | 現状                   | 対応が必要なこと                                                                     |
| ---------- | ---------------------- | ------------------------------------------------------------------------------------ |
| 選手資格   | 支配下区分だけで選択可 | 契約保留、FA、契約、翌季年俸、加入・昇格時期、前年現役ドラフトを出典付きで判定する。 |
| 高年俸例外 | 判定なし               | 例外1名と通常枠2名以上、1億円未満という境界を検証する。                              |
| 同票       | シード抽選             | 当年新人ドラフト第2巡の球団順に切り替える。                                          |
| 予備指名   | 指名時に自由変更可     | 希望先を指名可能なら原則固定し、指名不能の場合だけ変更可能にする。                   |
| 第2巡      | 独自の交換モデル       | 3区分の参加、再確認、入札条件と優先順位、条件付きの成立処理へ置き換える。            |

この調査記録を保存しただけで、指名エンジンや全選手の資格判定を修正済みとはしない。確認済みの制度・実装済みの処理・未確認の選手データを区別する。

## 実装への反映

ユーザー承認後、`2026-salary-proxy-v2` として年俸例外検証、FA資格者・前年現役ドラフト等の除外、同票時の2026年指名順、予備指名の拘束、第2巡の3区分参加・条件付き入札を実装した。現行の範囲と未確認事項は [RULES.md](RULES.md) を参照。選手別の非公表契約情報と議長の内部調整まで確認済みとはしない。
